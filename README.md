# Iris Data Representation
A Python implementation demonstrating how the Iris dataset can be represented and explored using a Pandas DataFrame and Seaborn.

## Technologies Used
* Python
* Pandas
* Seaborn
* Matplotlib
* Google Colab

## Dataset
Iris Dataset.

## Topics Covered
1. Iris Dataset Loading
2. Pandas DataFrame
3. Data Representation
4. Dataset Exploration
5. Data Visualization

## Purpose
This repository demonstrates the representation and basic exploration of Machine Learning data using Pandas and Seaborn.
